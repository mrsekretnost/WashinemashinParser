# Парсер стиральных машин с доставкой в Георгиевск

Интерактивное приложение и система мониторинга цен на стиральные машины из масс-маркет сетей (**DNS, М.Видео, Ситилинк**) с подтвержденной доставкой в **г. Георгиевск (Ставропольский край)**.

---

## 🚀 Быстрый запуск

На вашем рабочем столе уже созданы ярлыки:
1. **`Washers_Georgievsk.lnk`** — открывает веб-интерфейс в браузере.
2. **`Price_Monitor_Georgievsk.lnk`** — фоновый мониторинг цен с Windows-уведомлениями.

Либо запуск через командную строку:
```bat
start.bat
```

---

## 🛠 Возможности

- **Фильтрация каталога**:
  - Магазины: DNS, М.Видео, Ситилинк
  - Диапазон цен (слайдер)
  - Бренды (LG, Samsung, Haier, Beko, Indesit, Candy, Gorenje, Hisense и др.)
  - Тип загрузки: Фронтальная / Вертикальная
  - Минимальная загрузка белья (от 5 до 10+ кг)
  - Максимальная глубина корпуса (для узких помещений до 35-45 см)
  - Инверторный двигатель / прямой привод, пар, сушка
  - Поиск по названию модели
- **Геолокация**:
  - Фиксация региона Георгиевск (Ставропольский край).
  - Отображение статуса курьерской доставки на дом или самовывоза.
- **Экспорт**:
  - Выгрузка отфильтрованных результатов в **Excel (.xlsx)** и **CSV**.
- **Мониторинг цен**:
  - Добавление интересующих моделей в список отслеживания в 1 клик.
  - Установка желаемой целевой цены.
  - Построение графика динамики цены.
  - Всплывающие Windows-уведомления при падении цены.
