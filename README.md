# Парсер и инструмент сравнения цен на стиральные машины (г. Георгиевск)

Интерактивное приложение для поиска, прямого сравнения цен и мониторинга скидок на стиральные машины из масс-маркет сетей (**DNS, М.Видео, Ситилинк**) с подтвержденной доставкой в **г. Георгиевск (Ставропольский край)**.

---

## ⚡ Запуск на любом чистом ноутбуке / ПК

Вам не нужно вручную устанавливать библиотеки или настраивать пути. 

### Вариант 1 (Автоматический):
1. Скачайте репозиторий (`Code -> Download ZIP` или через `git clone`).
2. Запустите файл **`setup.bat`** (или сразу **`start.bat`**).
   - Скрипт сам автоматически проверит наличие Python, установит нужные библиотеки (`pip install -r requirements.txt`), скачает движок браузера Chromium и создаст удобные ярлыки на Рабочем столе.
3. Всё готово! Откроется окно в браузере.

### Вариант 2 (Запуск без открытия консоли):
- Кликните по ярлыку на рабочем столе: **`Washers_Georgievsk.lnk`** (или файл `run_silent.vbs`). Консоль будет полностью скрыта, сразу запустится графический интерфейс.

## 🎯 Возможности системы

1. **Умное склеивание моделей из разных магазинов**:
   - Приложение находит заводской артикул стиральной машины и объединяет ее в единую карточку.
   - Сразу видно, сколько стоит одна и та же модель в **DNS**, **М.Видео** и **Ситилинке**.
   - Самая выгодная цена помечается бейджем **«ЛУЧШАЯ»**, а сверху отображается размер экономии (например, *«Выгода до 6 000 ₽»*).
2. **Точная геолокация (Георгиевск)**:
   - В DNS, М.Видео и Ситилинке автоматически устанавливаются куки и регион Ставропольского края / Георгиевска.
   - Проверяется статус курьерской доставки крупной бытовой техники на дом.
3. **Фильтры под любые требования**:
   - Диапазон цен (слайдер)
   - Бренды (LG, Samsung, Haier, Beko, Indesit, Candy, Gorenje, Hisense и др.)
   - Тип загрузки: Фронтальная / Вертикальная
   - Загрузка (кг): от 5 до 10+ кг
   - Глубина корпуса: узкие (от 33 до 45 см) и полноразмерные
   - Инверторный двигатель, прямой привод, пар, сушка
   - Чекбокс **«🔥 Только модели в нескольких магазинах»** для быстрого поиска супер-скидок
4. **Выгрузка отчетов**:
   - Экспорт сравнительной таблицы со всеми ценами в **Excel (.xlsx)** и **CSV**.
5. **Мониторинг цен**:
   - Кнопка **«🔔 Отслеживать цену»** на карточке.
   - Настройка порога срабатывания и всплывающие Windows-уведомления при падении цены.

## 📦 Файлы проекта

- `app.py` — основной графический интерфейс с группировкой моделей и сравнением.
- `scraper.py` — диспетчер сбора данных.
- `parser_dns.py` — модуль сбора каталога DNS.
- `parser_mvideo.py` — модуль каталога М.Видео.
- `parser_citilink.py` — модуль каталога Ситилинк (GraphQL).
- `monitor.py` — фоновая служба отслеживания цен и уведомлений.
- `database.py` — база данных SQLite (`washers.db`).
- `start.bat` / `setup.bat` — скрипты запуска и автоматической установки зависимостей в 1 клик.
- `run_silent.vbs` — запуск без появления окна терминала.
